# Fuzzy-Agile-Development
Проект, содержащий материалы магистерской диссертации "Подходы к инженерии требований при гибкой разработке ПО с использованием аппарата нечетких множеств" (eng. "Fuzzy Set-Based Approaches to Requirements Engineering in Agile Software Development")

## Описание репозитория
Репозиторий создан с целью обеспечения прозрачности исследования, воспроизводимости полученных результатов и структурированного хранения материалов, сформированных в ходе выполнения работы. В него включены программный код исследования, исходные расчетные файлы, промежуточные аналитические артефакты, материалы, связанные с использованием генеративных моделей, а также сопроводительная документация проекта.

## Структура репозитория
### Приложение A_Программная реализация
Программная реализация расчетов выполнена на языке *Python*, что позволяет представить расчетный механизм в виде алгоритма, сделать процесс вычисления быстрым и гибким, так как входные параметры могут легко меняться пользователем в зависимости от решаемой задачи. Файл представляет собой интерактивный вычислительный блокнот Jupyter.
Алгоритмы расчета моделей приведены в том же порядке, что и в практической части данной работы под соответствующим заголовком, содержащим указание на вид модели приоритизации требований, а также используемый математический аппарат (четкая или нечеткая модель).
Реализация каждой модели представляет собой автономный и завершенный алгоритм, не требующий для исполнения и получения итогового результата запуска кода других методов приоритизации (или если предполагается выполнить расчеты только при помощи четкой или нечеткой модели).
### Папка Файлы загрузки и выгрузки данных
Для тех алгоритмов файла с кодом **Приложение A_Программная реализация**, где загрузка входных данных предусмотрена из файла *Excel* (с выгрузкой результатов расчетов также в виде файла электронных таблиц), предусмотрено использование файлов «Загрузочные данные *MoSCoW*_один эксперт» (для модели принятия решения одним стейкхолдером по методу *MoSCoW*), «Загрузочные данные MoSCoW _коллектив» (для моделей коллективного принятия решений по методу *MoSCoW*), «Загрузочные данные_Fuzzy RICE_один эксперт» (для модели принятия решения одним стейкхолдером по нечеткой модели *RICE*), «Загрузочные данные_четкий RICE_один эксперт» (для модели принятия решения одним стейкхолдером по модели *RICE* в четком виде) из папки **Файлы загрузки и выгрузки данных/ Загрузочные файлы**.

Также в этой папке находятся **итоговые файлы выгрузки** в Excel, которые являются результатом выполнения алгоритмов с загрузочными файлами из папки Файлы загрузки и выгрузки данных/ Загрузочные файлы.

### Приложение B_Примеры расчетов в Excel
Алгоритмы расчетов, изложенных в практической части работы, для наглядности представлены в виде электронных таблиц Excel с входными данными и результатами расчетов, в котором каждая модель оформлена на отдельном листе книги с соответствующим названием.
Дополнительная распаковка или обработка данных не требуется.

### Приложение C_Ментальные карты проекта
Для построения ментальной карты плана задач, которые необходимо решить для достижения цели работы, выбран cервис IOctopus (https://mind-map-online.ru).
В папке размещены файлы первоначального и окончательного планов исследования. Дополнительная распаковка или обработка данных не требуется.



### Приложение D_Ментальные карты проекта


Здесь содержаться файлы приложений: A - программная реализация на языке Python, В - оформление моделей в электронных таблицах Excel, С - ментальная карта проекта, D - PERT-диаграмма проекта, E - таблица взаимосвязи литературных источников, а также папка с файлами загрузочных форм для программной реализации и выгрузки с итогами моделирования.
