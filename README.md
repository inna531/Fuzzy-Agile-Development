# Fuzzy-Agile-Development
Проект, содержащий материалы магистерской диссертации "Подходы к управлению требованиями при гибкой разработке ПО с использованием аппарата нечетких множеств" (eng. "Fuzzy Set-Based Approaches to Requirements Management in Agile Software Development")

Здесь содержаться файлы приложений: A - программная реализация на языке Python, В - оформление моделей в электронных таблицах Excel, С - ментальная карта проекта, D - PERT-диаграмма проекта, E - таблица взаимосвязи литературных источников, а также папка с файлами загрузочных форм для программной реализации и выгрузки с итогами моделирования.
